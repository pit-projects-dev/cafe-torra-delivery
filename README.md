## 📋 Sobre o Projeto
Este repositório consolida a evolução prática do Projeto de Intervenção (PIT II), transformando a especificação ágil e a modelagem de negócio desenvolvidas no PIT I em uma solução web real, funcional e escalável para uma cafeteria gourmet. O sistema abrange uma vitrine virtual imersiva de cafés especiais, controle dinâmico de carrinho, customização de moagens, pagamentos via Pix com QR Code, rastreamento e painel administrativo.

---

## 🔄 Backlog do Produto (Histórias de Usuário Priorizadas)
O planejamento ágil estruturou o desenvolvimento do software nas seguintes Histórias de Usuário (US):
* **US01:** Cadastro de Cliente (Validação e Criptografia)
* **US02:** Visualização da Vitrine de Cafés com Filtros Sensoriais
* **US03:** Carrinho de Compras e Customização de Moagem/Tamanho
* **US04:** Finalização de Pedido (Checkout com Endereço e Frete)
* **US05:** Pagamento via PIX com QR Code Dinâmico e Timeout
* **US06 a US15:** Módulos de notas sensoriais, rastreamento em tempo real, cupons de desconto, controle de insumos e relatórios gerenciais administrativos.

---

## 🗄️ Estruturação do Banco de Dados (Projeto Físico MySQL)
O sistema conta com um banco relacional otimizado composto por 5 tabelas principais (`usuarios`, `categorias`, `produtos`, `pedidos`, `avaliacoes`), cujos scripts completos encontram-se no arquivo `database.sql` deste repositório.
